WILDFIRE DETECTION & MONITORING SYSTEM

To Run the Project (2 Commands):

1. Start Backend:
    python -m uvicorn main:app --host 0.0.0.0 --port 8000

2. Start Frontend Server (use port 8081 - port 8080 is used by PostgreSQL):
    cd frontend
    python -m http.server 8081
    
    Then open in browser:
    http://localhost:8081/index.html

That's it! The system will:
✅ Fetch 42,000+ fires from NASA FIRMS
✅ Display them on an interactive map
✅ Auto-update every 10 minutes
✅ Cluster moderate fires (no lag!)
✅ Show severe fires individually (red dots)


═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Backend takes 5-10 minutes to start?
→ Initial ETL is fetching all fires from NASA. Wait for it to complete.

Map not loading?
→ Check backend is running on port 8000: http://localhost:8000/health
→ Check frontend is running on port 8081

No fires showing?
→ The ETL runs every 10 minutes. Wait for initial data load.
→ Check browser console for errors (F12)
